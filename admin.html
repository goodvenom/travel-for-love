Travel for love — gallery admin

Owner-only page for adding a photo or video to the gallery on goodvenom.github.io/travel-for-love. This page is not linked from the site's menu — it only opens if you type /admin.html directly. It does nothing useful without your own GitHub token, so visitors cannot use it.

Step 1 — Sign in with a GitHub token

GitHub does not let a static page sign you in with a password, so this page uses a Personal Access Token (PAT) instead. Think of it as a password that only works for this one repo, and that you can revoke at any time.

Create your token (do this once, on GitHub — about 2 minutes):
  1. Open github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens and click Generate new token.
  2. Under Repository access, choose Only select repositories and pick only goodvenom/travel-for-love — nothing else.
  3. Under Permissions → Repository permissions, set Contents to Read and write. Leave everything else unset.
  4. Set a short expiry (for example 30 days). When it expires, GitHub will simply stop accepting it and you create a new one.
  5. Click Generate token and copy it immediately — GitHub shows it only once.

Keep that token private. Anyone with it can edit this repo. Never paste it into a chat, an email, or a file in the repo. It is stored only in this browser (localStorage) when you paste it below, and is sent only to api.github.com. To erase it from this browser, use “Forget token / log out”. To kill it everywhere, delete it on the same GitHub tokens page.
